# سياسة مقارنة المتحدثين للعرض التجريبي

في اختبار محلي بتاريخ 6 أكتوبر 2026 لست عينات في مجلدي ابن باز وابن عثيمين ومقطع ماهر، ظهرت درجتان بين هويتين مختلفتين بحسب أسماء المجلدات: 0.902060 و0.921981. تأكيد هويات العينات بالسماع ومصادرها ما زال مطلوبًا.

رفع حد التشابه المرتفع من 0.90 إلى 0.95 إجراء محافظ مؤقت، وليس معايرة نهائية. الدرجات من 0.80 إلى أقل من 0.95 غير حاسمة؛ الدرجات الأقل من 0.80 تشابه منخفض. حتى الدرجة المرتفعة لا تؤكد هوية المتحدث أو سلامة التسجيل.

هذا التعديل يضع أيضًا زوجًا من عينات ابن باز بدرجة 0.941851 في المنطقة غير الحاسمة. لا يجوز ادعاء دقة عامة من هذه المجموعة الصغيرة؛ يلزم اختبار تسجيلات مستقلة مؤكدة الهوية تشمل متحدثين إضافيين وجودات مختلفة. المحرك الحالي يحلل أول 20 ثانية فقط.

الواجهة تعرض مؤشر التشابه كدرجة تقنية من 1.00، وليس نسبة احتمال. اختبار API يستخدم نتائج نموذج بديلة للتحقق من السياسة فقط، وليس دقة WavLM.

## التثبيت والتحقق

أوقف السيرفر قبل فك الحزمة. نفذ من مجلد المشروع:

```bash
unzip -o ~/Downloads/baseerah-comparison-policy-update.zip -d ~/baseerah
python -m pytest -q tests/test_speaker_comparison_policy.py
npm run test:ui
python -X faulthandler -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

أعد المقارنة بعد تحديث الصفحة. الحزمة لا تغير أوزان النموذج أو ملفات العينات أو عتبات أداة تحديد الهوية المنفصلة.
