# تحديد الاقتباس والسياق في نسخة بصيرة التجريبية

## ما تغير

يرجع مسار التحقق بالنص والصورة والصوت حقل `quote_excerpt` عندما يوجد تطابق واحد لأربع كلمات متتابعة على الأقل داخل النص المسترجع، بعد تجاهل التشكيل وتطبيع الألف وعلامات الترقيم. يعرض الحقل نص المصدر الأصلي وموقعه بالحروف وما قبله وما بعده داخل الجزء المفهرس. تبقى المقاطع المجاورة متاحة في `context_trace`.

المطابقة اللفظية تستطيع الآن العثور على اقتباس قصير داخل جزء أطول دون أن تخفضه نسبة مقارنة طول النصين وحدها. يحتفظ محرك المطابقة بالنص المرشح الذي أنتج أفضل نتيجة، ويقارن المصادر المتميزة بدل تكرار المصدر نفسه بسبب مرشحات OCR/ASR المتعددة.

## حدود النتيجة

- `is_partial_chunk` يعني أن الاقتباس جزء من النص المفهرس، وليس دليلًا على تحريف المعنى.
- `audio_origin_verified` يبقى `false`: لا توجد مطابقة موجة صوتية أو توقيت داخل التسجيل الأصلي.
- لا يُختلق سياق خارج النصوص المفهرسة. إذا كانت الوثيقة ناقصة، فالسياق ناقص أيضًا.
- العبارات الأقصر من أربع كلمات، أو الظهور المتكرر داخل الجزء نفسه، لا ينتج عنها موضع اقتباس مؤكد.
- اختلاف التفريغ الصوتي أو صياغة الكلام قد يمنع التطابق اللفظي؛ يستمر مسار الاسترجاع الدلالي بدون ادعاء مطابقة حرفية.
- عتبات البصمة الصوتية السابقة لا تتغير بهذا التحديث.

## تطبيق التحديث

أوقف السيرفر بـ Ctrl+C، ثم نفذ من مجلد المشروع:

```bash
cd ~/baseerah
unzip -o ~/Downloads/baseerah-context-update.zip -d ~/baseerah
source .venv/bin/activate
python -m pytest -q
python -X faulthandler -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

حدث الواجهة وافتح `/ui/pages/quote.html`. مثال من قاعدة المعرفة الحالية:

> الصلوات الخمس والجمعة إلى الجمعة ورمضان إلى رمضان

ينبغي أن يظهر المصدر ونص الاقتباس والسياق الموجود في نفس الجزء. هذا اختبار اقتباس نصي، وليس اختبار الأصالة الصوتية أو دقة النموذج.
