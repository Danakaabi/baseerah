## الوظائف

- الصوت: POST /verify/audio/full. عرض المحتوى والسياق وهوية المتحدث ومؤشرات الصوت الصناعي منفصلة.
- النص: POST /verify/text.
- الصورة: POST /verify/image.
- مقارنة الصوتين: POST /verify/speaker. تقيس هوية المتحدث، ولا تثبت تطابق التسجيل أو انعدام القص.
- المصادر: GET /tools/sources من chunks.json الفعلي.
- البصمة: POST /tools/fingerprint؛ SHA-256 وسجل SQLite محلي. إعادة الملف نفسه تُرجع السجل الأصلي.
- فحص نسخة: POST /tools/fingerprint/check؛ مقارنة البايتات بالبصمات المسجلة.
- السجل والمحفظة: تخزين على الجهاز فقط؛ حفظ السجل اختياري ومعطل افتراضيًا. المحفوظات تحفظ بموافقة المستخدم عبر زر الحفظ. لا تحفظ وسائط الملفات.
- الأدلة والبحث فيها: محتوى إرشادي محلي.
- صفحة الرادار تعرض إحصاءات عمليات هذا الجهاز فقط. لا ترصد منصات التواصل.

## نطاق النموذج

سجل البصمة ليس شهادة رسمية، ولا يثبت هوية جهة أو حقوق ملكية أو صحة المحتوى. المراجعة البشرية توصية وليست نظام إرسال طلبات. تحليل القص والدمج غير مفعّل. درجات النماذج ليست احتمالات معايرة.

المكتبات الثقيلة تُحمّل عند أول استخدام، حتى تعمل الواجهة والمصادر والبصمة قبل تحميل نماذج AI. لم تُغيّر أسماء النماذج أو حدود المطابقة.
