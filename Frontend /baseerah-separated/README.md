# BASEERAH Frontend - Separated Version

## Structure

- `index.html` — الصفحة الرئيسية
- `pages/` — كل واجهة في ملف HTML مستقل
- `css/styles.css` — جميع التنسيقات المشتركة
- `js/app.js` — جميع وظائف JavaScript المشتركة
